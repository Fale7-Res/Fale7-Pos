FALAH RESTAURANT OS - FINAL PROTOTYPE VERSION 3.0

التشغيل في VS Code:
1) فك ضغط الملف بالكامل.
2) افتح المجلد في VS Code.
3) شغّل npm install ثم npm run dev.
4) افتح http://localhost:3000.
