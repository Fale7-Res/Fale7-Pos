# أرشيف التوثيق القديم

هذا أرشيف استرجاع، وليس حالة المشروع الحالية. ابدأ العمل من [README الرئيسي](../../README.md) و[نقطة الاستلام](../CODEX_TAKEOVER_20261108.md).

- [الأرشيف المضغوط](documentation-20261108.zip): يحفظ 9,157 ملفًا تاريخيًا بمساراتها الأصلية، إضافة إلى 280 نسخة من ملفات التوثيق والتعليمات قبل التنظيف.
- [دليل الملفات والبصمات](documentation-20261108-manifest.json): ابحث عن المسار القديم لتعرف اسم المدخل داخل ZIP وبصمة SHA-256.
- تتضمن الملفات التاريخية التقارير المستوردة، تقارير التدقيق الثلاثة، و16 تقرير تقدم/تسليم وخريطة قديمة. الملفات الثلاثة PROGRESS وREMEDIATION_PLAN وREMEDIATION_PROGRESS في docs أصبحت توجيهات قصيرة للتوافق؛ النص الأصلي الكامل هنا.
- توجد نسخة MANIFEST.json داخل ZIP نفسه. لقطات الملفات التي ظلت نشطة موجودة داخله تحت before-cleanup/.
- تحققت مطابقة SHA-256 لكل 9,437 حمولة قبل إزالة الملفات القديمة. حجم ZIP: 112,634,081 بايت.
- SHA-256 للأرشيف: 4e44026d964057d789c2824ca9eb44276cf4f34ef53ed889155de56910b22d9f

للاسترجاع، افتح ZIP واستخرج الملف أو المجلد المطلوب إلى مكان مؤقت ثم راجعه قبل إعادته. مراجع المسارات وأرقام السطور التاريخية داخل All Issues تشير إلى النصوص الأصلية المحفوظة هنا.

الكود الحالي وملفات التشغيل والترحيلات وسجل العيوب وأدلة الاختبارات الحالية لم تُحذف ضمن هذا التنظيف.
