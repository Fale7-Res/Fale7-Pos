# B09 — Self-starting, logged print agents

**Issues:** PRT-0012, PRT-0011, PRT-0010 · **Started:** 2026-11-06

## Analysis (falah-analyst)

**Verdict: READY.**

**Orchestrator decision D1 (engineering, 2026-11-06): Option A.** The agent never exits because of login.
- With no server response, it retries with back-off: 2 s, doubling, up to a 60 s cap.
- On a refusal that carries a status (401/403/429/5xx, or the client's local pre-check), it waits `PrintServerClient.RefusedLoginPause` (5 min) and retries.
- Exit code 3 is retired.

**Option B was rejected** (exit 3 and let the service restart it):
- Each restart is a fresh process with no login pause, so a dead PIN would be sent about once a minute.
- `LoginAttemptGuard` allows 5 wrong PINs per source per 15 min and 20 per day.
- The Receipt agent shares the cashier PC's source address, so the till on that PC would be locked within about 5 minutes.

### PRT-0012: still present
**Evidence**
- `src/Falah.PrintAgent/Program.cs`:
  - `:138-148` makes one login attempt; any exception returns 3.
  - `:165-166` creates the shutdown CTS only after login.
  - `:127-136` takes the route mutex on the main thread.
- `PrintServerClient.cs`:
  - `:77-79`: a call made inside the pause throws `StatusCode = Unauthorized`, whatever the real status was.
  - `:84-85`: any non-success response sets a 5-minute pause.
- No tool registers an agent as a service; `tools/install-falah-service.ps1` covers only the server.
- The csproj has no service hosting, so `sc.exe` would fail with error 1053.

**Fix**
- **New `AgentLogin.LogInAsync(server, pin, log, ct, delay?)`:**
  - implements the D1 policy;
  - rethrows `OperationCanceledException` on cancellation;
  - never logs the PIN.
- **Program.cs:**
  - create the CTS and the `CancelKeyPress` handler before login;
  - move the body after the mutex, unchanged, into `RunAgentAsync(ct) -> int`;
  - add a `--service` branch.
- **New `AgentWindowsService`:** a `ServiceBase` from the package `System.ServiceProcess.ServiceController` 8.0.1, which is already cached in `.nuget-packages`.
  - **The route mutex must stay acquired on the main thread before `ServiceBase.Run`.** A mutex abandoned by a retired thread is treated as free (Program.cs:130), which would duplicate tickets.
  - `OnStart` starts the run task and returns.
  - `OnStop` cancels, calls `RequestAdditionalTime`, and waits about 20 s.
  - A non-zero result sets `ExitCode` and calls `Stop()`.
  - In service mode, call `Directory.SetCurrentDirectory(AppContext.BaseDirectory)`.
  - Catch `UnauthorizedAccessException` on the Global mutex and map it to exit 4.
  - Keep the agent's `Program` internal.
- **New `tools/install-falah-print-agent-service.ps1`:**
  - parameters: `-Route`, `-ServiceName FalahPrintAgent-<Route>`, `-PublishPath`, `-ConfigPath` (default `%ProgramData%\Falah\PrintAgent\<Route>\`; never overwritten), `-Uninstall`;
  - requires an administrator, and refuses while a console agent runs for that route;
  - checks that a PIN source exists without reading it, and restricts the secrets file with icacls;
  - creates the service with `start= auto`, `depend= Spooler` for the windows transport, and failure actions restart 5000/5000/60000 with `failureflag 1`;
  - runs as LocalSystem.
- **Docs:**
  - PRINT_AGENT.md: running it, a new service section, the exit-code table;
  - GO_LIVE_CLEANUP_CHECKLIST row 12.4;
  - DEPLOYMENT.md section 1;
  - DAILY_OPERATIONS_VERIFICATION: the power-cut drill.

**RED tests**

### PRT-0011: still present
**Evidence**
- `Program.cs:21` logs only to the console.
- The error paths write only to `Console.Error`.

**Fix**
- **New `AgentLog(dir, route, maxBytes = 5 MB, keepFiles = 5)`:**
  - writes `yyyy-MM-dd HH:mm:ss zzz message` under a lock, with FileShare.ReadWrite;
  - rolls over by size to `.1` … `.N`;
  - keeps one file per route (`print-agent-<Route>.log`);
  - falls back to the console and warns once.
- **`AgentOptions.DataDirectory` + `ResolveDataDirectory()`:**
  - empty means `%ProgramData%\Falah\PrintAgent`;
  - relative paths resolve against `AppContext.BaseDirectory`;
  - logs go to `<DataDirectory>\logs`.
- **Program.cs:** every Log and every Console.Error line also goes to the file, and unhandled exceptions are logged.

**RED tests**
- `AgentLogTests.The_agent_keeps_a_log_file_that_rolls_over_by_size` (AgentLog is added console-only first).
- `AgentLogTests.Login_failures_in_the_log_never_carry_the_pin`.
- If `appsettings.json` gains a key, keep `AgentOptionsSecretTests` green.

### PRT-0010: still present
**Evidence**
- `PrintJobProcessor.cs:125-126`: Remember is called outside the try. An IOException there:
  - aborts `DrainAsync`;
  - the loop then logs "poll failed" forever, and the route stalls behind that job.
- `PrintJobProcessor.cs`, other unguarded writes:
  - `:139`: `Forget` sits inside the report retry;
  - `:155`: the final Remember is unguarded.
- `UnreportedAttemptStore.cs`:
  - `:76-83` updates memory before Save;
  - `:35-44`: `ForRoute` never probes the folder.
- `Program.cs:155`: a corrupt journal crashes the agent.

**Fix**
- **(a) Write probe in `ForRoute`.**
  - Write a probe file, move it with overwrite, then delete it.
  - On failure, throw `InvalidOperationException` naming the folder and the user.
  - Program exits 5 before login; a corrupt journal also exits 5.
- **(b) Default journal location `<DataDirectory>`.**
  - Merge the old per-route and shared files from `AppContext.BaseDirectory`, taking only entries the new store lacks.
  - Never delete the old files.
  - Skip the merge when both folders are the same.
- **(c) Report failed instead of stalling.**
  - Keep the Remember-before-send at :106-108 exactly where it is, with a journal-specific failure reason.
  - Wrap :125 (warn and continue to the report).
  - Move or guard `Forget`, and guard the final Remember.
