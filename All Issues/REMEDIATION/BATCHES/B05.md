# B05 — Refund only collected money

**Issues:** FIN-0007 · **Started:** 2026-11-06 · **Owner decision:** refuse until collected (2026-11-06)

## Analysis (falah-analyst)

**Verdict: READY.** No migration, no DTO change, no client change.

### FIN-0007 — still present, and wider than the issue says
- `src/Falah.Domain/Orders/Order.cs:240-252` (`ApplyRefund`) checks only Cancelled, Multi and the amount.
- `src/Falah.Infrastructure/Orders/RefundOrderHandler.cs:78-93`: the only money guard is the protected-balance check. `ApplyRefund` follows at :126.
- **Wallet is not protected** (`src/Falah.Domain/Financial/PaymentMethod.cs:19`: Protected = Main, Drawer, Bank, InstaPay). A refund of a pending Wallet order therefore pushes tre-wallet negative.
- **The WinUI till already refuses these refunds** (`CashierViewModel.Refund.cs:20-21`, `IsPaid: true`). The gap is server-side: the API and the legacy WPF client.

### What "collected" means (adopted by the orchestrator)
- **Cash or card, not cash-on-delivery:** IsPaid is set at checkout.
- **InstaPay / Wallet:** collected once confirmed (`Order.ConfirmElectronicPayment`, Order.cs:178-184).
- **Cash on delivery:** collected only once a **Settled** driver-custody row exists. This is the codebase's own definition (`ReportingQueryService.LoadOrderIdsWithCashOutsideRestaurantAsync`, :55-82). "Delivered, cash still with the driver" = not collected.
- **Split:** already refused (FIN-0005, out of scope).

### Fix
- **Domain:** `Order.AssertCollectedForRefund(bool cashOnDeliverySettled)`.
  - A pending electronic payment gives the message "لا يمكن استرجاع طلب لم يتأكد تحويله الإلكتروني بعد…".
  - An unsettled COD order gives "لا يمكن استرجاع طلب دفع عند الاستلام قبل تحصيل ثمنه وتسوية عهدة السائق.".
  - Otherwise, a not-paid order gives "لا يمكن استرجاع مبلغ لم يُحصَّل.".
  - `ApplyRefund(OrderRefund refund, bool cashOnDeliverySettled = false)` calls it after the existing Cancelled and Multi checks.
  - **The messages must not promise a cancel action** for an undispatched COD order. None exists (FIN-0051).
- **Handler:** right after `OrderMapper.ToDomain` (:78), and before the clamp and the balance guard:
  - compute `cashOnDeliverySettled` = COD && `DriverCustodies.Any(OrderId == id && Status == Settled)`;
  - call `AssertCollectedForRefund`;
  - pass the flag to `ApplyRefund` at :126.

  The replay check stays first.
