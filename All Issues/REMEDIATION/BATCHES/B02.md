## Analysis (falah-analyst)

**Verdict: READY.** No migration; no client change.

**PAYR-0001 is still present.**
- `src/Falah.Domain/Payroll/PayrollRules.cs:18` allows Approved → Paid.
- `src/Falah.Infrastructure/Employees/TransitionPayrollHandler.cs:26,32,37,55,59` sets Status=Paid with no money posted, needing only `employees_manage`.
