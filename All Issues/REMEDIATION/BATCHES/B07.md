# B07 — Endpoint-enumeration test and gating of sensitive reads

**Issues:** ARCH-0001, SEC-0001, SEC-0002, SEC-0003, SEC-0004, SEC-0005, INV-0008, CUS-0001
**Started:** 2026-11-06
**Owner decision:** employee, payroll, backup, purchase, supplier and cost data are readable by the owner/`all` only; customer data stays readable by order takers (2026-11-06).

## Analysis (falah-analyst)

**Verdict: READY**, split into **B07a**, then **B07b**. All changes are server-side, with no migration, no money or time logic, and no change to any client DTO shape.

### Orchestrator rulings on the analyst's questions (2026-11-06)
- **Q1, already-gated cost reads:** routes already gated on `reports_view` stay as they are (financial-report, the inventory cost, overview, detail, loss and variance reads, recipe costs, food-cost, the daily-statement employee rows, the owner-dashboard payables).
  - B07 gates only the ungated routes.
  - Whether to tighten these to `all` is a permission grant, so it is an **owner question** and is not changed here.
  - `CanReadCosts` is a single helper, so either answer is a one-line change.
- **Q2:** the owner's "delivery" order takers means `delivery_manage`. There is no "delivery" permission key; `delivery_manage` is the Customers screen's own permission.
- **Q3:** the withheld cash-discrepancy threshold is sent as `0`, keeping the `long` shape, with a doc comment. There is no contract change.
- **Q4:** the payroll-rule settings (overtime rate, late grace, penalty multipliers) stay visible for now. Noted for the owner.
- **Q5, owner-facing consequence:** holders of `employees_manage`, `employees_ledger`, `attendance_manage`, `payroll_*`, `backup_manage`, `purchasing_manage` or `suppliers_manage` who do not hold `all` lose the read screens for those areas but keep their write permissions. This follows directly from the owner's decision. The seeded roles are unaffected: the manager and owner hold `all`.

### Helpers (Program.cs, next to `RequirePrintAgent`)
```csharp
// Owner decision 2026-11-06 (REMEDIATION_PLAN § Decisions, SEC-0001/0002): "all" only.
static IResult? RequireOwner(HttpContext http) => RequireAnyPermission(http, "هذه البيانات متاحة للمالك فقط.");
static bool CanReadCosts(HttpContext http) => RequireOwner(http) is null;
static bool Holds(HttpContext http, params string[] anyOf) => RequireAnyPermission(http, "", anyOf) is null;
```
Every gate goes **first**, before any lookup or try block, so an unknown id still gets 422 and not 404.
