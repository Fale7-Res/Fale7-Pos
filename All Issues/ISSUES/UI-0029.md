## 1. Original source references

Remediation loop, batch B01 analysis (All Issues/REMEDIATION/BATCHES/B01.md), confirmed by the orchestrator against source.

## 2. Affected components

CashierViewModel.Pickup (RequestedPickupAtUtc, PickupSummary); CashierViewModel.Checkout (request building)

## 3. Current code evidence

`src/Falah.Client.CashierWinUI/ViewModels/CashierViewModel.Pickup.cs:35-43` — getter builds the local pickup DateTime and calls `TimeZoneInfo.ConvertTimeToUtc(local, BusinessClock.CairoTimeZone)`; for 00:00–00:59 on the last Friday of April the local time is invalid and the call throws ArgumentException. Used by PickupSummary, by checkout request building (CashierViewModel.Checkout.cs ~:394) and by Pickup.cs ~:91.

## 4. Relevant historical evidence

Same root cause as [FIN-0028](FIN-0028.md) (invalid local time at the DST jump).

## 5. Expected behaviour

An invalid local pickup time is refused with a clear message (or normalised to the first valid instant); no exception from a property getter.

## 6. Actual code-supported behaviour

An unhandled exception is thrown from a binding getter, which may crash or break the pickup editor.

## 7. Root cause

Local-to-UTC conversion without an `IsInvalidTime` check.

## 8. Business impact

Low likelihood (a pickup booked for that hour on one night a year), but crash-prone.

## 9. Reproduction / failure scenario

Pick 2027-04-30 at 00:30 as the pickup time.

## 10. Existing safeguards

Pickup-time validation exists server-side (CheckoutRules, past or too far).

## 11. Missing safeguards

An invalid-time check on the client.

## 12. Recommended remediation

Use a shared domain helper (added with FIN-0028) that converts a Cairo local time to UTC and reports invalid times; show the cashier a validation message.

## 13. Alternative approaches

Restrict the time picker to valid times.

## 14. Required regression tests

Client view-model test: a pickup at 2027-04-30 00:30 yields a validation message and no exception.

## 15. Related issues

[FIN-0028](FIN-0028.md); [UI-0007](UI-0007.md)

## 16. Dependencies and prerequisites

B01 (FIN-0028) domain helper.

## 17. Acceptance criteria

No exception for any picked time; an invalid time is explained.

## 18. Remaining uncertainty

The WinUI binding behaviour on a getter exception was not observed.
