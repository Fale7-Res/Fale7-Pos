## Reproduction and cause

Ten toasts and the header "ف" used fixed colours chosen for Light. In Dark they rendered low-contrast text.

## Change

- Toast text uses `CardBackgroundBrush` on a `TextPrimary` background, or `AccentTextBrush` on Danger.
- The header monogram uses `AccentTextBrush`.
- The POS offer banner uses theme brushes.

## Evidence and limits

- Tests: `CashierThemeLiteralTests` reject literal colours in the toasts and also check that every XAML file in both clients is well formed. It was added after a bulk edit produced a malformed attribute that crashed the XAML compiler.
- Limit: contrast ratios were not measured instrumentally.
