## Fix 2026-11-22 (owner decisions)

Owner decision 2026-11-22: food cost is frozen at business-day close. CloseBusinessDayHandler writes each order's line unit cost (OrderItems.FrozenUnitFoodCostPiastres) and packaging cost (Orders.FrozenPackagingCostPiastres / FrozenPackagingMissing, FoodCostFrozenAtUtc) at that moment (migration AddFrozenFoodCost, additive nullable); the food-cost report and the dashboard use the frozen figures for those orders and the live estimate (FoodCostCalculator) only for days still open. Unknown stays unknown. An order frozen by an earlier close of a reopened day keeps its first figures. Tests: BusinessDayCloseVerticalSliceTests A_closed_day_keeps_the_food_cost_it_closed_with_when_prices_change_later (RED: 600 instead of 200) and A_day_still_open_follows_the_latest_price; close/reporting/dashboard/profitability/inventory run 126/126.
