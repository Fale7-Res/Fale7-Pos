## Reproduction and cause

- **What it looked like:** the close-day checklist marks each row done or not done with a check or empty-circle icon only.
- **What assistive technology got:** the row button's UIA name was the label alone ("فحص الطابعة") both before and after toggling. A screen reader user could not tell which required items blocked the close.

## Change

- **Helper:** `ControlCenterViewModel.ChecklistAccessibleName` returns "label، تم/لم يتم[، إلزامي]".
- **XAML:** the row's `AutomationProperties.Name` binds to it through `ChecklistAccessibleNameConverter`. This replaces the earlier label-only name.
- **Unchanged:** the shared DTO.

## Evidence and limits

- **Tests:** `ChecklistAccessibleNameTests` (3).
- **Native:** toggling "فحص الطابعة" stored a completion (`ChecklistCompletions`: completed by مدير المحل). The rows now read "فحص الطابعة، تم" and "عد درج النقدية، لم يتم، إلزامي".
- **Limit:** not heard through Narrator.
