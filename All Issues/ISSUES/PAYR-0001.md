## 1. Original source references

Copilot register FIN-006

## 2. Affected components

PayrollRules.Transitions; TransitionPayrollHandler; PayPayrollHandler

## 3. Current code evidence

src/Falah.Domain/Payroll/PayrollRules.cs:13-21 allows Approved → Paid; src/Falah.Infrastructure/Employees/TransitionPayrollHandler.cs:36-56 only sets run.Status (no treasury movement, no ledger settlement).

## 4. Relevant historical evidence

No additional historical evidence beyond the sources listed.

## 5. Expected behaviour

Paid only via PayPayrollHandler, which posts the treasury payment and settlement entries.

## 6. Actual code-supported behaviour

An employees_manage holder can set Paid with no money posted.

## 7. Root cause

Generic state machine includes a money-bearing terminal state.

## 8. Business impact

Run shows Paid; employees unpaid; ledgers never settled.

## 9. Reproduction / failure scenario

Manager advances the run status once more after approval.

## 10. Existing safeguards

PayPayroll idempotency key per run.

## 11. Missing safeguards

Transition guard.

## 12. Recommended remediation

Remove Approved → Paid from generic transitions; Paid reachable only from PayPayrollHandler.

No meaningful alternative identified.
