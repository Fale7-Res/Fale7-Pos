## Reproduction and cause

On the menu and pricing screen, every product row's button was exposed to UI Automation as "تبديل التوفر". A screen reader heard the same words on every row, with no product and no direction.

## Change

- **Name:** `MenuProductRow.ToggleAccessibleName` returns "إيقاف توفر {product}" or "إتاحة {product}". It updates when availability changes, and the row button's `AutomationProperties.Name` binds to it.
- **Unchanged:** the visible text.

## Evidence and limits

- **Tests:** `MenuRowAccessibleNameTests` (2).
- **Native:** the button read "إيقاف توفر كبدة اسكندراني". Invoking it set the product unavailable in the database, and the name became "إتاحة كبدة اسكندراني". It was then restored.
