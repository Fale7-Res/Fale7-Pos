## 4. Relevant historical evidence

No additional historical evidence beyond the sources listed.

## 5. Expected behaviour

Agents start and recover automatically after power cuts.

## 6. Actual code-supported behaviour

Printing stays down until someone restarts each agent.

## 7. Root cause

One-shot startup login; no service wrapper.

## 8. Business impact

No kitchen tickets after any reboot until noticed.

## 9. Reproduction / failure scenario

Power returns; stations boot before the server.

## 10. Existing safeguards

Durable queue (nothing lost, only delayed).

## 11. Missing safeguards

The remediation below.

## 12. Recommended remediation

Startup login retry with back-off; service registration with restart-on-failure.

## 13. Alternative approaches

No meaningful alternative identified.

## 14. Required regression tests

Agent started before server → logs in once server is up.
