## Current remediation — 2026-11-07

B35: station string constructors reject remote HTTP before transport creation. Server validates configured URLs/Kestrel/HTTP_PORTS before database startup, rejects remote HTTP requests independently of spoofable forwarded headers; agents validate addresses before login. Default certificate validation preserved. Loopback development remains allowed. Explicit server/agent recovery override is logged. RED5client +4server cases; GREENclient223/223 and server/agent32/32. Real TLS certificate installation, station trust and end-to-end on-site acceptance remain pending; see docs/LAN_DEPLOYMENT.md.
