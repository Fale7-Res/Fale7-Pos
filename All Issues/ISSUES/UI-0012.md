## 3. Current code evidence

src/Falah.Client.CashierWinUI/ViewModels/BackupViewModel.cs:273 compares "Completed"; enum is {Requested, Succeeded, Failed, Blocked} (src/Falah.Infrastructure/Persistence/Entities/BackupRecordEntity.cs:4).

**Same screen, same root cause (added 2026-11-06, B14 analysis, orchestrator re-read):** the verification label and the verify-result note compare `VerificationStatus` with `"Verified"`/`"Failed"` (`BackupViewModel.cs:55-60,166`), but the server writes `"Valid"`/`"Invalid"` (`src/Falah.Infrastructure/Backup/VerifyBackupHandler.cs:53,60`; also read as `"Valid"` by `ScheduledBackupService.cs:112,136` and `DailyStatementQueryService.cs:258`). Every verified backup is therefore shown as "لم يتم التحقق من سلامة الملف", and a successful verify shows "نتيجة التحقق: Valid" instead of the success note.
