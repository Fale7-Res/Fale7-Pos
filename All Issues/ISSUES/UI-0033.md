# UI-0033 — The Call Center had no dark theme; on a dark Windows it mixed dark system controls with fixed light panels

| Field | Value |
|---|---|
| Canonical ID | UI-0033 |
| Category | UI / theming |
| Severity | Medium |
| Priority | P2 |
| Implementation status | **FIXED** |
| Verification level | CURRENT_TEST_VERIFIED |
| Confidence | High |
| Historical aliases | `NEW (Claude Phase 1b, 2026-11-08)` |
| Evidence date | 2026-11-08, b3071be + working tree |

**Evidence.**
- `Styles/Colors.xaml` was a single flat dictionary.
- Views bound brushes with `StaticResource`.
- 21 surfaces used literal `White` or hex colours.
- Converters read `Application.Current.Resources[key]`, which always resolves the app-level theme, not the window's.
- There was no theme preference.

**Fix.**

| File | Change |
|---|---|
| `Colors.xaml` | Light and Dark `ThemeDictionaries`, generated from one key → (light, dark) table. Light keeps the existing values unchanged; Dark follows the Cashier's dark palette with the Call Center's green brand lightened. |
| New semantic keys | `CardBackground`, `Overlay`, `AccentText`, `BrandTint`, `SubtleSurface`, `InputSurface`, `SegmentText`, `SuccessSoft`, `OfferBorder`, `OfferText` |
| Views and `Controls.xaml` | `ThemeResource` everywhere; literal colours mapped to the semantic keys |
| `Services/ThemeService.cs` (new) | Per-station preference file `callcenter-appearance.json`: System, Light or Dark |
| `Services/ThemeResources.cs` (new) | Theme-aware converter brushes that follow the window root |
| `MainWindow` | Applies `RequestedTheme` live |
| Header | `ThemeToggle` button: System → Light → Dark |

**Tests.**
- `CallCenterThemeTests`: both themes define the same keys; brushes carry literal colours; no view paints a colour the theme cannot change.
- RED: 12 failed. Log: `artifacts/claude-20261107/callcenter-theme-red.log`.
- GREEN: client suite 277/277. Native x64 build: 0 warnings, 0 errors.

**Native evidence** (`artifacts/claude-20261107/ui/callcenter-theme/`):
- Login, order desk, order lookup (including the not-found error), delivery editor, size picker and populated cart, in Dark at 1920 (125% scaling).
- The theme switched live Dark → System → Light without a restart; the preference was persisted.
- Populated cart in Light and Dark at 1366×768 layout units and at the 150% equivalent (1280×720 units).

**Not done.**
- No contrast measurement; checked by eye.
- Keyboard-only navigation pass not performed.
