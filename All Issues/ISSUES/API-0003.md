## 1. Original source references

All Issues Mission A

## 2. Affected components

ApiClient.ReadResultAsync; RetainedRequest; global exception handler

## 3. Current code evidence

src/Falah.Client.CashierWinUI/Services/ApiClient.cs:83 `OutcomeUnknown = StatusCode >= 500`; src/Falah.Client.CashierWinUI/Services/RetainedRequest.cs:41-46 keeps the request when OutcomeUnknown; src/Falah.Server/Program.cs:307 global handler returns 500 for unmapped exceptions (e.g. FK DbUpdateException, [MENU-0002](MENU-0002.md)).

## 4. Relevant historical evidence

No additional historical evidence beyond the sources listed.

## 5. Expected behaviour

Deterministic failures surface as definitive errors the operator can resolve.

## 6. Actual code-supported behaviour

Every retry 500s; request stays pending; station operations blocked (HasUnresolvedOperation).

## 7. Root cause

Status-class heuristic; unmapped domain/database failures become 500.

## 8. Business impact

Station lockouts for management operations.

## 9. Reproduction / failure scenario

[MENU-0002](MENU-0002.md).

## 10. Existing safeguards

True transient 5xx are safely retried.

## 11. Missing safeguards

The remediation below.

## 12. Recommended remediation

Map known database/rule failures to 409/422; include a "retryable" flag in error bodies; offer discard after N identical 5xx.

## 13. Alternative approaches

No meaningful alternative identified.

## 14. Required regression tests

Client test: repeated 500 with retryable=false → refusable/discardable.
