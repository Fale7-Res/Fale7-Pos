# UI-0034 — Cart lines ran to both panel edges (Call Center and Cashier POS): ItemsControl Padding is ignored

| Field | Value |
|---|---|
| Canonical ID | UI-0034 |
| Category | UI / layout |
| Severity | Low |
| Priority | P2 |
| Implementation status | **FIXED** |
| Verification level | CURRENT_TEST_VERIFIED |
| Confidence | High |
| Historical aliases | `NEW (Claude Phase 1b, 2026-11-08)` |
| Evidence date | 2026-11-08, b3071be + working tree |

**Evidence.**
- Native Call Center screenshot `callcenter-theme/light-1920-cart.png`: the "+" button and the item names touched or passed the cart panel's right edge, and "ملاحظات التحضير" sat outside its left edge.
- Cause: `<ItemsControl Padding="16,0">`. The default `ItemsControl` template does not apply `Padding`.
- The same pattern was found in the Cashier: `CartPanelView` (POS cart) and `DailyStatementView`.

**Fix.** `Margin` instead of `Padding` in all three places.

**Native evidence.** `light-1920-cart-after.png`, `dark-1366-cart-after.png`, `dark-150pct-equiv-cart.png`: the lines are inset like the rest of the panel.

**Not done.** No automated test; this is layout-only and is proven by the native captures. The Cashier POS cart was not re-captured with items after the fix.
