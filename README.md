# فالح — ابدأ من هنا

نظام كاشير وإدارة مطعم بالعربية: خادم .NET وSQL Server، برنامج كاشير وإدارة، برنامج كول سنتر، ووكيل طباعة. ده مدخل التوثيق؛ لا تحتاج قراءة كل الملفات.

## الملفات الأساسية

| عايز تعرف إيه؟ | المرجع |
|---|---|
| وصلنا لفين وإيه المتبقي والمعطّل؟ | [الحالة الحالية](docs/CODEX_TAKEOVER_20261108.md) |
| طلباتك: تسليم الوردية وورقتها وكشف كل سائق | [طلبات المالك](docs/UI_OWNER_REQUESTS.md) |
| المشروع فيه إيه وشاشاته ووظائفه؟ | [شرح المشروع بالعربي](docs/PROJECT_OVERVIEW_AR.md) |
| إيه اتجرب واتصلح في الواجهة؟ | [تقرير الواجهة](docs/UI_VERIFICATION_AND_CHANGES.md) |
| المشاكل وحالة كل واحدة | [السجل المركزي](All%20Issues/01_MASTER_ISSUE_REGISTRY.md) |

شرح المشروع أقدم من آخر دفعة إصلاح؛ استخدمه لخريطة المكونات، وارجع للحالة الحالية لأرقام الاختبارات والقيود. المشروع لم يُعلن جاهزًا للإنتاج.

## للمنفّذ

- [CLAUDE.md](CLAUDE.md): قواعد العمل والبناء والسلامة.

- [تكليف الواجهة](docs/CLAUDE_UI_ONLY_TASK.md) و[جدول فحص الإجراءات](docs/UI_CONTROL_VERIFICATION_MATRIX.csv): تغطية الشاشات والأزرار.

## الأرشيف

التقارير المستوردة ونسخ أدواتها القديمة وتقارير التدقيق ومراحل التقدم القديمة جُمعت في [أرشيف واحد قابل للاسترجاع](docs/archive/README.md)، بعد فحص كل ملف ببصمته. أُزيلت 9,154 نسخة ملف تاريخية من الشجرة، وحُوّلت 3 ملفات قديمة إلى توجيهات قصيرة حفاظًا على توافق التعليمات. الكود والتشغيل وسجل العيوب وأدلة الاختبارات الحالية باقية.
